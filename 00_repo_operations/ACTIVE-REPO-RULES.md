```text

```

`SPARK-LAB-STB` is the active product and operating system repo for:

- client-facing interface patterns

## Working rule

Do not spread one build across multiple repos.

Other repos may be referenced, but active STB deliverables should be adapted and committed here.

## Promotion rule

A reference idea becomes part of STB only when it is:

1. translated into STB language,
2. placed in the correct folder room,
3. connected to the STB offer ladder,
4. reviewed against STB boundaries,
5. committed into this repo intentionally.

## Boundary rule

Do not copy large blocks from reference repos into this repo without adaptation.

Do not add unrelated project files just because they are useful elsewhere.

If the work does not help sell, deliver, explain, or operate Spark Lab STB, it does not belong in V1.

## Default build posture

- markdown-first
- folder-first
- no app unless proven necessary
- no dependency installation unless required
- no fake scaffolding
- no generic AI course structure
- no random content dump

## Human review gate

Before merging structural changes, confirm:

- the active repo is correct
- the folder room is correct
- the change supports STB
- the change does not introduce unnecessary complexity
