# CONTEXT — Visual Workflows

## Purpose

This folder turns the Spark Lab STB platform into simple visual maps that can be used for:

- webinar slides
- Gumroad PDFs
- pitch decks
- client onboarding
- internal operator training
- future app UX planning

## Operating rule

Do not make visual maps that overwhelm the audience.

A map should reduce cognitive load.

The public-facing visual should show the next calm step. The operator-facing visual may show the backend architecture.

## Inputs

Use source material from:

- `00_doctrine/`
- `01_business_pressure_test/`
- `02_stb_sprint/`
- `03_continuity_os/`
- `04_webinar_os/`
- `05_gumroad_assets/`
- `06_client_interface/`

## Outputs

This folder should produce Mermaid maps and later exported PNG/SVG/PDF visuals.

Current V1 maps:

1. STB Platform Map
2. Webinar Funnel Map
3. Client Journey Map
4. 12-Agent Mob Map

## Review gate

Before using a map publicly, ask:

1. Does this make STB easier to understand?
2. Does this reduce overwhelm?
3. Does this help someone know the next step?
4. Does this separate client-facing simplicity from backend complexity?

If not, simplify the map.
