# 09 Visual Workflows

This room holds visual workflow maps for marketing, webinar teaching, operator onboarding, and platform planning.

These diagrams are written in Mermaid so they can be rendered in GitHub, documentation tools, slide decks, and future app documentation.

## Core maps

- `STB_PLATFORM_MAP.mmd` — the full Spark Lab STB offer ladder.
- `WEBINAR_FUNNEL_MAP.mmd` — the lead capture and conversion path.
- `CLIENT_JOURNEY_MAP.mmd` — the human transformation path.
- `12_AGENT_MOB_MAP.mmd` — the backend STB agent operating model.

## Design principle

The visuals should make the system feel clear, not bigger.

Use them to show:

```text
pressure → pattern → pause → proof → pathway
```

The client should see calm progression. The operator can see the engine.
